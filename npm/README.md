# virial

GPU physics simulation in Rust and WebGPU, in the browser and natively.
Science first: energy-conserving methods, SI units, and results you can
measure, rendered to video.

**Early development.** This package reserves the name. A browser build of the
engine will be published here later. Follow progress in the
[repository](https://github.com/anshullaikar/virial-engine); the Rust crate is
[`virial` on crates.io](https://crates.io/crates/virial).
