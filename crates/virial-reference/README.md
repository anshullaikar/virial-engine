# virial-reference

CPU versions of [Virial](https://github.com/virial-engine/virial-engine)'s
solvers, written for clarity rather than speed. Tests run each GPU solver
against these in f64 to put a number on the GPU's error. The same code also
runs in f32 to show what plain single precision would give.
