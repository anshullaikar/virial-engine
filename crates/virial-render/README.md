# virial-render

Drawing for [Virial](https://github.com/virial-engine/virial-engine):
particles as glowing sprites or shaded spheres, coloured by group or by a
value through perceptual colour maps (viridis, inferno), orbit cameras with
keyframed paths for videos, and text readouts drawn into the frame.

Includes the public-domain font8x8 by Daniel Hepper and the CC0 colour maps by
Nathaniel J. Smith, Stefan van der Walt and Eric Firing.
