# virial

GPU physics simulation in Rust and WebGPU, in the browser and natively.
Science first: energy-conserving methods, SI units, and results you can
measure, rendered to video.

**Early development.** This release only opens a window or browser canvas and
draws through WebGPU. Particle dynamics, measurement and video export are on
the way to 0.1.0. See the [repository](https://github.com/anshullaikar/virial-engine).
